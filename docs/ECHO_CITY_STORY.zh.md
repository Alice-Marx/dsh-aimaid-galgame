# 当前 Gal 剧目：回声之城正篇与旧城迁移篇

当前独立 GAL 插件只打包两部作品。剧情模式在本机运行，不要求模型账号；自由模式会调用 DeepSeek Harness 中已配置的模型路线，可能产生费用。

| 剧目 | 剧情内容 | 游玩提示 |
| --- | --- | --- |
| **回声之城·正篇** | 序章、共通线八章、六条角色主线、隐藏线「影与身」、命名之夜与 TRUE END。 | 从序章顺序游玩会保留选择、旗标与好感度；隐藏线及 TRUE END 有剧情条件。 |
| **旧城迁移篇：未写完的约定** | 旧城迁移与 DeepSeek 的约定，保留原版剧情节点、场景映射与分支。 | 使用旧城篇既有的自动进度和历史三槽键。 |

## 正篇快速开始

1. 打开 **Gal 模块 → 剧情模式**，标题画面选择 **回声之城·正篇**。
2. 点 **开始新故事**从序章开始；已有进度点 **继续阅读**。
3. 点 **继续**推进对话，遇到分支时选择选项。对话工具栏可查看历史、好感度、章节与 Gal 设置。
4. **存 1–3 / 读 1–3**用于长期检查点；快捷存档用于临时回退。跨 profile 或清理应用数据前先导出 JSON 备份。
5. 如需体验隐藏线，从序章顺序游玩并完成雪国线真结局、第四章短笺完整抄录、两次留意执事日常。TRUE END 还需完成六条角色线与隐藏线。命名之夜可输入执事名字，默认「衔雪」。

主线共通八章后可切换章节；正篇会保留本周目的旗标和 14 位角色好感度。王女线有真／暗双结局，其他角色线各自收束；满足条件后可以到达 TRUE END「回声之城」。

## 旧城迁移篇

旧城篇使用旧版本剧情引擎。现有用户可从标题画面的剧目列表选择 **旧城迁移篇：未写完的约定**；没有旧存档时则从开篇开始。故事选择与正篇分开自动保存，历史三槽保持旧键兼容。

## 角色立绘

自由模式的角色选择会按供应商或模型名匹配对应人物。MiMo 使用 `mimo/Mimo.png`；Mistral 使用 `Mistral/Mistral.png`。两张原图均以对应文件名单独打包。此前错误映射到 MiMo 的 Mistral 图已改正；旧文件另存于 companion archive，不参与本版构建。基础图、源图哈希和尺寸见[立绘来源清单](GAL_ART_SOURCES.zh.md)。

## 剧目拆分与存档

《千桥协议》《雪灯来信》《未寄出的春天》的剧本、专属立绘、专属背景、生成脚本和旧说明保存在同级 companion 项目 `F:\everyAI\all\model-router-galgame-optional-stories`。被正篇或旧城篇共同使用的背景仍保留在独立 GAL 项目；其余内容不进入独立 GAL 插件源码、客户端 bundle 或 npm tarball。

升级时，独立 GAL 插件不会清理其他剧目原有的本地存档键；不过本插件不再含这些剧目的引擎，因此隐藏剧目存档不能在本插件内继续游玩。要继续旧剧目，请从 companion archive 恢复其独立工程或使用旧版插件，并先备份 DeepSeek Harness profile 数据。

## 验收清单

1. Gal 标题画面只有 **回声之城·正篇**、**旧城迁移篇：未写完的约定** 两个选项。
2. 正篇序章、章节选择、分支、全身立绘、背景、音乐、存档与导入导出正常；跨章不丢本周目旗标。
3. 旧城篇可从旧自动存档继续；三槽仍读取原进度。
4. 自由模式检查 MiMo、Mistral 的全身图与角色名；Mistral 模型不应显示 MiMo 立绘，MiMo 模型也不应显示 Mistral 立绘。
5. 打包后检查 npm tarball 的文件列表，不应含 `archive/`、春篇 90 张差分、春篇背景或其他已拆分剧目引擎。

播放器的立绘大小/位置、音乐、快进、自动阅读和快捷键见[Gal 设置与播放器教程](GAL_SETTINGS.zh.md)。
